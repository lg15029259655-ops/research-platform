# 研究活动图形与匹配说明

## 匹配边界与复核

- 以步骤主要活动为准：微流控细胞捕获优先微流控；政策问卷优先问卷；患者来源细胞培养优先细胞；生态野外采样优先实地观测。
- 模糊的“分析”“验证”“干预”不会自动代表某个学科。名称涉及多个具体活动或只有抽象词时，规则仍可能选错；不能声称覆盖全部学科或理解论文语义。
- 修改分类时同步检查关键词顺序、图形映射、正反例与已有素材；不要要求终端用户为图形分类做选择。
